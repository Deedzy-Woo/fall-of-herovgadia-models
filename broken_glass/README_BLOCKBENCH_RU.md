# Broken Glass — Blockbench

Все PNG встроены в проекты. Распакуйте ZIP и откройте файл через File → Open Model.

- blockbench/broken_glass.bbmodel — полный стеклянный куб 16×16×16.
- blockbench/broken_glass_pane.bbmodel — панель с соединениями на восток и запад, толщиной 2 пикселя.
- blockbench/broken_glass_comparison.bbmodel — общая сцена: куб, прямая панель, угол, перекрестие и окно 3×2.
- Остальные pane_*.bbmodel показывают все 16 статических схем соединений. n/e/s/w означают север/восток/юг/запад, isolated — без соседей.

Геометрия и UV панели собраны из стандартных моделей Minecraft 1.21.1 и существующего multipart blockstate. Это визуальные снимки состояний: внутри Blockbench соединения автоматически не переключаются. Java Block/Item используется для отдельных блоков; Generic Model — для общей сцены.

Полупрозрачные текстуры и выбитые фрагменты сохранены. Фон редактора влияет на заметность стекла. Игровой вид с сортировкой прозрачности смотрите на приложенном скриншоте broken-glass-windows.png.
