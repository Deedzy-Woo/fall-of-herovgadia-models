# Проверка исправленного полёта гарпии

Проверен файл `undead_harpy.bbmodel`, SHA-256:
`8d462829817c6cd533c9e5a4b522734a9e7b0b258fe6505a401711e443e3dc6e`.

Модель открыта и воспроизведена в настоящем Blockbench 4.12.6: 92 редактируемых кубоида, 24 кости, 12 клипов, исходная текстура 64×64. Ошибок JavaScript при загрузке и проверке не обнаружено.

- Проверены 612 поз: по 81 фазе `fly`, `glide`, `carry`, по 41 фазе остальных клипов. Обе кисти соединены с предплечьями во всех проверенных позах. Минимальное перекрытие OBB: слева 0,7187, справа 0,3036 единицы модели.
- Пересечений противоположных крыльев, заходов свободных перьев через среднюю плоскость тела и пересечений свободных перьев с твёрдой геометрией корпуса не найдено.
- Проверены все части крыльев, включая внутренние накладки, относительно черепа, челюсти и клюва: пересечений не найдено в 11 самостоятельных клипах. `hurt` является аддитивной реакцией; для него дополнительно проверены 459 сочетаний с `fly`, `glide`, `carry`, также без этих пересечений. Исходный клип `hurt` сохранён целиком.
- В `carry` манекен неподвижен: центр `[0, 9.6, -12.5]`, габарит 9,6×28,8×9,6. Во всех 81 фазе четыре когтистые конечности касаются нужных областей видимого тела; глубоких пересечений торса и головы манекена не найдено. Манекен присутствует только в превью и не добавлен в модель.
- Начало и конец трёх циклов, а также пять стыков цепочки захвата совпадают по мировым матрицам всех 24 костей: максимальная ошибка 0.
- В `attack_dive`, `special_warning`, `death`, `death_fall`, `death_land` исходные аниматоры всех частей, кроме крыльев, сохранены без изменений.

Контакт креплений крыльев с плечами и касания задних прядей волос учитываются отдельно. Они сохраняются; утверждение о полном отсутствии любых пересечений геометрии не делается. Дополнительное смещение крыльев не разрывает крепление: минимальное перекрытие креплений с корпусом при сочетании `fly` + `hurt` составляет 0,610 слева и 0,551 справа.
