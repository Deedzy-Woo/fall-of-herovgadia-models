# Осквернённые растения — Fall of Herovgadia

Четыре самостоятельных декоративных растения:

| ID | Вид | Видимая высота |
| --- | --- | --- |
| `fallofherovgadia:corrupted_plant_small` | Низкий редкий сухой пучок | 5 пикселей |
| `fallofherovgadia:corrupted_plant_medium` | Искривлённый ветвистый сорняк | 11 пикселей |
| `fallofherovgadia:corrupted_plant_tall` | Тонкий высокий сухой стебель с погибшей семенной головкой | 15 пикселей |
| `fallofherovgadia:corrupted_plant_withered_bush` | Широкий густой мёртвый куст | 11 пикселей |

## Модели и текстуры

- `blockbench/*.bbmodel` — четыре проекта Blockbench в формате Java Block/Item, с двумя пересекающимися плоскостями и встроенными текстурами.
- `textures/*.png` — четыре самостоятельные текстуры 16×16 с прозрачностью. Только резкие пиксельные края, без сглаживания; приглушённые серо-коричневые и грязно-оливковые тона.
- `src/main/resources/assets/fallofherovgadia/` — готовые blockstates, block models с `minecraft:cutout`, item models и PNG.
- `src/main/resources/data/fallofherovgadia/` — таблицы добычи и отдельный тег подходящей почвы.
- `lang_additions/` — новые русские и английские названия для добавочного объединения с существующими переводами.

Модели используют ванильный `minecraft:block/cross`, без biome tint. Варианты поворота 0/90/180/270° выбираются обычной системой blockstates. Значки предметов используют соответствующие прозрачные спрайты через `minecraft:item/generated`.

## Подключение в реальный мод

Цель: Minecraft 1.21.1, NeoForge 21.1.235, Java 21. В этом репозитории нет основного класса мода и Gradle-сборки, поэтому комплект **не является готовым JAR**, а код регистрации пока не подключён к точке входа.

Два Java-файла в `src/main/java/com/herovgad/fallofherovgadia` следуют схеме существующего `BrokenGlassBlocks`:

- `CorruptedPlants.java` — четыре блока, четыре предмета и вкладка природных блоков.
- `CorruptedPlantBlock.java` — обычное поведение растения: отсутствие коллизии, моментальное разрушение, проверка почвы и размер выделения по варианту.

Для переноса в рабочий проект из корня распакованного комплекта:

```sh
python3 tools/install_corrupted_plants.py --mod-dir /path/to/actual-mod --dry-run
python3 tools/install_corrupted_plants.py --mod-dir /path/to/actual-mod
```

Установщик отказывается перезаписывать отличающиеся файлы и объединяет языковые записи, сохраняя существующие. Затем **один раз** добавьте в существующий конструктор `FallOfHerovgadia`, рядом с другими регистрациями:

```java
CorruptedPlants.register(modEventBus);
```

Используется существующая константа `FallOfHerovgadia.MODID`. Нового основного класса мода создавать не нужно.

В текущем checkout новые ресурсы и Java-файлы также размещены непосредственно под корневым `src/main`, а четыре перевода добавлены к существующим языковым файлам. Основной класс отсутствует, поэтому вставить вызов регистрации здесь некуда.

## Почва и поведение

Отдельный тег `fallofherovgadia:corrupted_plant_soils` разрешает почвы из `#minecraft:dirt` (в том числе обычную и грубую землю) и `fallofherovgadia:corrupted_soil`, если этот блок зарегистрирован. Глобальные теги других блоков не изменяются. Без подходящего блока снизу растение не должно сохраняться; это выполняет стандартный `BushBlock`.

Лёгкое растение без физической коллизии, с обычным небольшим горизонтальным смещением. Таблица добычи содержит только один собственный предмет, без специальных наград. Нет роста, распространения, случайных тиков, эффектов, урона, генерации мира, анимаций или специальных частиц.

## Что проверено

- Все четыре PNG имеют размер 16×16 и только альфу 0/255; силуэты различаются, все непрозрачные пиксели связаны с основанием.
- Проверены ссылки blockstates → block model → texture, item model → texture, таблицы добычи, переводы и идентичность встроенных PNG.
- Все четыре `.bbmodel` открыты и отрисованы в официальном Blockbench 5.2.2. Проверены размеры перекрещенных плоскостей и rescale. Скриншоты: `previews/*_blockbench.png`; отчёт: `blockbench_validation.json`.
- Автономный просмотрщик отрисовал 12 сочетаний: четыре растения на обычной, грубой и осквернённой земле. Значки предметов показаны в нижней панели; кнопки переключения проверены Chromium. Отчёт: `viewer_validation.json`.
- Существующие языковые записи сохранены; прежние растения и остальные модели не изменены.

`corrupted_plants_viewer.html` открывается автономно; мышь вращает камеру и меняет масштаб. Превью сделаны из реальных PNG и моделей, **это не скриншоты Minecraft**.
