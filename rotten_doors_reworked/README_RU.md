# Rotten Doors — переработанные двери для Blockbench

8 самостоятельных редактируемых `.bbmodel` со встроенными PNG.
Откройте `blockbench/<порода>/rotten_<порода>_door.bbmodel` через **Файл → Открыть модель**.
Вручную назначать текстуры не требуется.

Каждая дверь состоит из двух отдельных элементов `door_top` и `door_bottom`.
Геометрия, UV и прозрачные оконные проёмы полностью сохранены относительно предыдущей коллекции.
Размер полной двери 16×32×3 единицы: 1 блок шириной, 2 высотой и 3/16 толщиной.
Новая верхняя и нижняя текстуры каждой двери — строго 16×16, RGBA, без сглаживания и анимации.
Отдельные PNG лежат в `textures/`.

## Изменения по породам

| Порода | Индивидуальные детали |
|---|---|
| Oak | Побитая оконная перемычка, короткие диагональные царапины на нижней филёнке, два небольших старых подтёка. |
| Spruce | Сырая вертикальная доска справа, светлая полоска обнажённого волокна, тусклые скобы и один нижний подтёк. |
| Birch | Согласованная светлая кремовая вставка обеих половин, короткий надрыв с тёмной сердцевиной и светлым краем, сырой нижний угол. |
| Jungle | Скол у правой нижней филёнки, локальное потемнение рамы, два небольших нижних следа. |
| Acacia | Выщербленная узкая перемычка, короткие царапины у нижней рамы, асимметричный влажный край. Высокие прорези сохранены. |
| Dark Oak | Глубокая сырость в правом нижнем углу, редкие светлые волокна, тусклая латунная ручка. Филёнки читаются. |
| Mangrove | Местный скол вдоль изогнутой филёнки, бурые сырые края и два тёмных кровяных следа. |
| Cherry | Скол рядом с резным проёмом, светлый потрёпанный край нижней филёнки, пыльный розовый цвет и один небольшой подтёк. |

Кровь — сдержанная, тёмная, по 1–2 тонких следа внизу каждой двери.
Нет общего повторяющегося узора износа: расположение повреждений выбрано под конструкцию каждой двери.

## Исправление берёзы

Вставка и обрамление обработаны как одна цельная дверь 16×32 перед разделением на две PNG.
Убрана резкая смена светлого и тёмного тона между половинами: разница средней яркости
двух соседних строк на стыке уменьшена примерно с 30 до 4 уровней из 255.
Локальные тёмные углы оставлены как следы сырости; светлая берёзовая основа сохранена.
Точные измерения лежат в `birch-tone-check.json`.

## Основа и область изменений

Палитра сверена с обычными гнилыми досками из вновь приложенного `rotten_wood_blockbench.zip`.
Эти исходные PNG досок совпадают с использованными ранее побайтово. Они не изменялись.
Обновлены только восемь дверей и их верхние/нижние PNG.
Это отдельная версия для оценки; ступеньки, плиты, заборы, калитки, люки и предыдущая библиотека не затронуты.

## Проверка

Все восемь проектов загружены в Blockbench. Проверены текстуры, грани,
редактируемые элементы и сохранение через project codec.
`previews/doors_blockbench.png` — рендер из Blockbench;
`previews/doors_pixel_preview.png` — точное пиксельное превью;
`previews/before_after.png` — сравнение с прошлой версией и исходными досками.

Java-кода, регистрации, игровых item JSON и отдельной предметной иконки в этой поставке нет:
по уточнённому запросу подготовлены только модели с текстурами для оценки.
Gradle и Minecraft не запускались. Работу открывания, освещение, обратную сторону двери
и предметное отображение следует проверить после будущей интеграции в мод.
