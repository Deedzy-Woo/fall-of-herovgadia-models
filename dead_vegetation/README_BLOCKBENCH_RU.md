# Dead Biome Vegetation — Blockbench

Распакуйте архив и откройте blockbench/dead_vegetation_comparison.bbmodel для просмотра всех 10 растений. В папке blockbench есть также отдельный проект каждого растения.

Все 14 исходных PNG встроены в проекты; искать или подключать текстуры отдельно не нужно. Общая сцена — Generic Model; отдельные растения — Java Block/Item.

Трава, цветок, кусты и папоротники используют точную геометрию vanilla cross (две двусторонние пересекающиеся плоскости). Высокая трава и большой папоротник собраны из верхней и нижней частей, общая высота 32 пикселя. Кактус повторяет ванильную модель с раздельными боковыми поверхностями и торцами. Biome tint отсутствует.

Верхний/дальний ряд: dead_short_grass, dead_tall_grass, withered_wildflower, dead_fern, dead_large_fern. Нижний/ближний ряд: dead_savanna_grass, dead_savanna_shrub, dead_cactus, frozen_dead_grass, frozen_dead_shrub. Все объекты подписаны в Outliner и могут скрываться по отдельности.

Это визуальные проекты. Регистрация блоков, размещение и работа двух половин в игре находятся в отдельном dead_biome_vegetation.zip. Блокбенч не исполняет игровую механику. Игровой скриншот и сравнительная таблица PNG приложены для ориентира.
