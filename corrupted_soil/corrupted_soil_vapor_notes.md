# Подключение слабых испарений позже

Текстура: assets/fallofherovgadia/textures/particle/corrupted_soil_vapor.png.
16×16 RGBA, ступенчатая прозрачность 12–42 из 255; свечение не используется.
Это только изображение: само по себе оно не создаёт частицы.

Позже зарегистрировать отдельный SimpleParticleType и клиентский SpriteSet/TextureSheetParticle provider средствами NeoForge 1.21.1. Добавить assets/fallofherovgadia/particles/corrupted_soil_vapor.json со списком textures: ["fallofherovgadia:corrupted_soil_vapor"].
Использовать PARTICLE_SHEET_TRANSLUCENT, обычное освещение мира, без fullbright и аддитивного смешивания. Цвет RGB уже задан в PNG: не умножать повторно на зелёный tint.

Из клиентского animateTick блока: только над открытой верхней гранью, примерно один шанс из 40 на вызов; одна частица в случайной точке поверхности на y+1.02. Начальные параметры для проверки в игре: размер 0.12–0.22 блока, жизнь 25–45 тиков, скорость вверх 0.003–0.008 блока/тик, минимальный боковой дрейф, плавное затухание alpha в конце.
PNG уже полупрозрачен: начальная alpha частицы 0.7–1.0, затем при необходимости ослабить после проверки. Поведение, видимость и частоту нужно оценить в игре.

Java, particle registration, blockstates и JSON-модели в этой задаче не менялись.
