# Заражённый тюк сена

- corrupted_hay_bale.bbmodel — блок для открытия в Blockbench, обе текстуры встроены. Вспомогательных плагинов не нужно. Мухи — игровые частицы; в этом статическом проекте их нет.
- previews/ — увеличенные текстуры и реальные снимки Minecraft с одиночным тюком и кучей 3×3×2.
- IMPLEMENTATION_RU.md — регистрация, параметры и результаты игровых проверок.
- corrupted_hay_bale.patch — изменения основного мода, применяется из корня его исходников.
- ../downloads/corrupted_hay_bale_implementation.zip — исходники и patch.
- ../downloads/corrupted_hay_bale_full_build.zip — тот же комплект плюс полный JAR мода 0.1.0. Это не отдельный аддон: не устанавливать вместе с прежним JAR того же мода. Требуются Minecraft 1.21.1, NeoForge 21.1.235, Java 21 и GeckoLib 4.8.3.
- ../downloads/corrupted_hay_bale_blockbench.zip — только проект Blockbench и PNG для удобного скачивания.

Генерация мира и существующие структуры не менялись. Основная реализация готовилась без commit/push; эта публикация сделана по последующему прямому запросу пользователя.
