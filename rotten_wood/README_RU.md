# Rotten & Cracked Wood Collection

48 непрозрачных RGB-текстур 16×16 и 32 стандартные JSON-модели Minecraft 1.21.1. Авторские рисунки созданы заново из отдельных волокон, стыков, коровых пластин, колец и локальных пятен гнили; не являются перекрашенными ванильными PNG. Ванильные изображения использованы только для сравнительных превью.

Дуб: грубая серо-коричневая кора; ель: тонкие тёплые тёмно-коричневые волокна; берёза: светлая бумажная кора и чёрные отметины; тропическое дерево: охристо-коричневые пластины; акация: широкая серая кора и оранжеватый торец; тёмный дуб: насыщенная тёмно-коричневая кора; мангр: буро-красная древесина и извилистые борозды; вишня: пыльный розовый и поперечные полосы коры.

Обычная гниль локальная, цельность древесины сохранена. Cracked дополнен осветлёнными продольными расколами с отдельной нерегулярной композицией для каждой породы и поверхности и светлыми кромками обнажённых волокон; торцы имеют радиальные повреждения. Превью показывают реальные PNG с nearest-neighbor, включая повторение 2×2.

Модели досок используют cube_all, брёвен — cube_column. Для оси Y модель готова; после регистрации блока оси X/Z задаются поворотом этой модели в будущих blockstates (X: x=90,y=90; Z: x=90). Blockstates, игровые регистрации и Java здесь не создавались.

Проверены количество, размеры, непрозрачность, уникальность PNG, различия версий, JSON и все ссылки. В игре не проверялось: блоки ещё не зарегистрированы. Gradle для графических ресурсов не запускался. Текстуры рассчитаны на повторение стандартными кубами, трещины не изменяют геометрию.

Коллекция опубликована по запросу автора проекта. В обычных и треснутых брёвнах дуба, ели, акации и тёмного дуба убраны ровная полоса обнажённой древесины и длинные прямые полосы коры; заменены короткими неравномерными волокнами; кора и трещины сохранены. Расположение трещин фиксировано в PNG; динамическая рандомизация блоков не добавлялась.
