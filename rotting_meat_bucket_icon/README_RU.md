# Ведро с гнилым мясом — готовая иконка

Основной ресурс: assets/fallofherovgadia/textures/item/rotting_meat_bucket.png — PNG 16×16 RGBA, прозрачный фон, только альфа 0/255, без анимации и сглаживания.

Масса выступает над ободком: крупные буро-красные куски, серо-розовые складки, тёмные полости, один приглушённый серо-зелёный участок и тёмно-красные подтёки. Железный корпус с ванильным силуэтом и контрастным левым бликом остаётся узнаваемым. Объём передан рисунком и силуэтом, не новой 3D-геометрией.

Визуальная основа — мясной блок и мясо в котле из приложенного rotting_meat_blockbench (8).zip; исходные PNG извлечены из встроенных текстур для изучения палитры. Текстуры самого блока, котла и исходный архив не изменялись. Увеличенный рабочий вариант изображения уменьшен до 16×16 методом nearest-neighbor и приведён к компактной палитре без полупрозрачных сглаженных краёв. Корпус ориентирован на ванильное ведро Minecraft; побайтовое совпадение с ванильным ведром не заявляется.

## Какие файлы использовать
1. PNG скопировать в src/main/resources/assets/fallofherovgadia/textures/item/rotting_meat_bucket.png. Если имя текстуры вашего предмета другое, переименовать PNG или поменять ссылку в его модели.
2. При необходимости использовать assets/fallofherovgadia/models/item/rotting_meat_bucket.json: это обычная item/generated модель для Minecraft 1.21.1, со стандартным отображением спрайта в инвентаре и руке. Поместить её в src/main/resources/assets/fallofherovgadia/models/item/. Имя JSON должно совпадать с ID уже зарегистрированного предмета. Для более новых версий Minecraft может потребоваться соответствующее этой версии описание предмета.
3. Если в моде уже есть корректная модель item/generated с этим путём текстуры, достаточно заменить PNG.

preview.png — реальные 16×16 пиксели, показанные на светлом/тёмном фоне и в размерах 16/32/64; увеличение nearest-neighbor. Это лист просмотра иконки, не игровой скриншот.

Проверены размер, формат, прозрачность, отсутствие анимации и соответствие ссылки JSON имени текстуры. Интеграция, Java, запуск Minecraft и Gradle не выполнялись. Ресурс создан без работы с Git; затем опубликован в репозитории моделей по отдельному запросу пользователя.
