# Bone piles — согласованная палитра и аккуратная укладка

Три проекта .bbmodel со встроенными текстурами. Кости используют оригинальные ванильные bone_block_side и bone_block_top. Рисунок скелетных черепов сохранён, серые оттенки поверхности заменены на тёплые костяные; глазницы и нос остаются тёмными.

Элементы уложены на поверхности нижних элементов с небольшим зазором: кости не проходят сквозь черепа и чужие костяные группы. Составные элементы одной кости/рёбер намеренно соединяются внутри группы. Черепа установлены последними, с открытыми лицами. Толщина костяных элементов слегка уменьшена для невысокой насыпи.

Small/medium: основание 1×1, large: единая композиция 2×2. Это визуальные проекты, без Java-кода регистрации. Превью отрисованы программно из геометрии и текстур. В игре не проверялось. Ванильные исходные материалы — Mojang/Microsoft, Minecraft Java 1.21.1; черепная палитра адаптирована.
