# Костяные кучи — проекты Blockbench

Откройте small_bone_pile.bbmodel, medium_bone_pile.bbmodel или large_bone_pile.bbmodel в Blockbench. Каждая модель содержит все семь текстур 16×16 внутри файла; отдельно подключать PNG не нужно. Исходные PNG лежат в textures/.

Small: низкая куча, один череп. Medium: более плотная насыпь, два черепа. Large: единая композиция в пределах площади 32×32 модельные единицы, пять черепов. В large нет разделения на четыре повторяющиеся кучки. Геометрия состоит из кубоидов с поворотами по Y, кости имеют утолщённые концы, есть обломки и сломанные рёбра. Сплошной кубической основы нет.

Формат проекта: Java Block/Item. large — целый исходный объект для визуального редактирования; для интеграции в мод потребуется разделить геометрию на части 2×2 и реализовать размещение/удаление в Java. Регистрация, коллизия и поведение в эту визуальную поставку не входят.

Превью отрисованы из геометрии и встроенных текстур проектов; это не скриншоты Minecraft или Blockbench. Проверки в игре и сборка мода не выполнялись. Комплект подготовлен для скачивания через GitHub.
