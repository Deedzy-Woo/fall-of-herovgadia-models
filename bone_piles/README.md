# Bone pile models — Minecraft 1.21.1

Ресурсы моделей для Fall of Herovgadia. Это не готовый исполняемый мод.

Small: низкая куча с одним черепом. Medium: более высокая плотная насыпь с двумя черепами. Large: общая асимметричная насыпь 32×32 модельных единицы с четырьмя черепами.

Скопировать содержимое src/main/resources в ресурсы мода. При слиянии lang-файлов сохранить существующие переводы.

Большой объект использует свойство part: north_west, north_east, south_west, south_east. Северо-западная часть — якорь; остальные размещаются на +X, +Z и +X+Z. Все четыре части используют одну глобальную композицию, геометрия распределена между ними без повторения. Полная модель large_bone_pile.json предназначена для просмотра; blockstate использует четыре частичные модели.

Нужен Java-код регистрации трёх блоков и предметов, свойства part, размещения четырёх частей и совместного удаления с одним выпадением. Код не включён: исходники мода не предоставлены. Коллизию задать неполными ступенчатыми VoxelShape. Не использовать стандартный полный куб.

Текстура: исходный сгенерированный атлас из трёх областей — кость, обломки, череп. Это увеличенный эскиз, не финальные текстуры 16×16. UV моделей уже указывают на соответствующие области.

По просьбе пользователя сборка, игровые проверки и тесты не выполнялись. Репозиторий не изменялся.

Ресурсы опубликованы в ../src/main/resources. [Скачать исходный комплект](../downloads/bone_pile_models.zip).
