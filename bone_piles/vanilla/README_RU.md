# Bone piles — оригинальные ванильные текстуры

Три .bbmodel для Blockbench. Геометрия, повороты, иерархия и идентификаторы кубоидов сохранены из предыдущей версии. Изменены только материалы и UV. Текстуры встроены в каждый проект, PNG подключать вручную не нужно.

Кости: оригинальные minecraft:block/bone_block_side и bone_block_top, 16×16. Черепа: оригинальная текстура minecraft:entity/skeleton/skeleton, 64×32; UV выбирают область головы 8×8 и нижние пиксели для челюсти. Текстуры скопированы без перерисовки из официального клиента Minecraft Java 1.21.1 Mojang.

Small и medium имеют основание 1×1; large — одна композиция на площади 2×2. Это редактируемые визуальные проекты, без регистрации и поведения блоков. Превью — программный рендер геометрии и материалов, не снимок игры.

Для собственной разработки Minecraft. Ванильные материалы принадлежат Mojang/Microsoft; они не объявляются оригинальными авторскими текстурами этого проекта.
