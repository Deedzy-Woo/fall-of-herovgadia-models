# Fall of Herovgadia — Rotting Meat: графические ресурсы

Minecraft 1.21.1 / NeoForge 21.1.235 / Java 21.

## Готовые объекты

- Полный куб 16×16×16 с авторскими текстурами складок, сгустков, тёмных полостей, серо-розовых тканей и небольших участков гнили.
- Три варианта куба, у каждого шесть самостоятельных рисунков граней: 18 разных композиций.
- Узнаваемый ванильный котёл с неодинаковыми мясными кусками, остатками на краях и небольшими внешними потёками. Содержимое — объёмная масса, верхние фрагменты доходят до y=18.1 при высоте бортика 16.

Палитра приглушённая: буро-красные и коричневые ткани, тёмные углубления, тусклые серо-розовые складки и редкие серо-зелёные участки. Все 22 PNG — 16×16 без сглаживания и анимации. 21 текстура RGB полностью непрозрачны; только atlas деталей котла использует RGBA с прозрачным фоном.

## Как посмотреть

В `blockbench/` находятся проекты с полностью встроенными текстурами:

- `rotting_meat.bbmodel` — одиночный блок.
- `two.bbmodel` — два соседних блока разных вариантов.
- `patch_3x3.bbmodel` — площадка из девяти блоков A/B/C.
- `volume_3x3x2.bbmodel` — скопление из 18 блоков.
- `rotting_meat_cauldron.bbmodel` — котёл с мясом.
- `comparison.bbmodel` — этот котёл рядом с обычным ванильным.

Открывать через File → Open Model. Основные проекты блока и котла — Java Block/Item; демонстрационные многоблочные сцены — Generic Model. Они предназначены для просмотра расположения нескольких блоков, а не для экспорта в один игровой блок.

В `previews/` есть восемь отдельных видов моделей, два общих листа, увеличенные текстуры и смешанная раскладка 3×3. Снимки сделаны в Blockbench 4.12.6 с этими ресурсами. Три вида котла сняты в ортографической проекции; изометрический — с равными компонентами направления камеры. Для масштабирования текстур и обзорных листов применён nearest-neighbor.

## Модульность

У вариантов A/B/C общая однопиксельная стыковочная кромка и короткие продолжения складок в точках стыка. Остальная периферия доступна для распределения органов и петель вплоть до краёв. Последний и первый столбцы совпадают, как и последняя и первая строки. Это даёт совместимые стыки между любыми из трёх вариантов по горизонтали и вертикали. Внутренние участки различаются положением складок, полостей, наростов и гнили.

Нет отдельной квадратной рамки по краям. Цвет и тканевые переходы сохраняются при сборке 2 блоков, 3×3 и 3×3×2. Для совпадения рассчитанных стыков сохраняйте исходную ориентацию UV: варианты не рассчитаны на независимые повороты верхних текстур на 90°.

Одинаковая текстура A при очень большой площади всё равно периодична через 16 пикселей; смешивание A/B/C уменьшает заметность повторения. Это набор совместимых вариантов для будущего выбора моделей. Автоматической connected-texture логики и определения соседей в комплекте нет.

## Модели для Minecraft

`src/main/resources/assets/fallofherovgadia/models/block/`:

- `rotting_meat.json` — вариант A.
- `rotting_meat_variant_2.json` — вариант B.
- `rotting_meat_variant_3.json` — вариант C.
- `rotting_meat_cauldron.json` — котёл с мясом.

Блок использует стандартный `minecraft:block/cube`. Его объём — полный куб; выпуклость складок передана пиксельной светотенью, что сохраняет геометрическое соединение соседних блоков.

Котёл содержит 13 неизменённых cuboid-элементов ванильного корпуса, 13 cuboid-элементов мясной массы и остатков, 8 тонких плоскостей с прозрачными деталями. Три куска повёрнуты вокруг Y на допустимые ±22.5°; все остальные осевые. Поверхности потёков смещены от железа, чтобы избежать z-fighting. Геометрия, UV и вращения поддерживаются обычными block models Minecraft.

Корпус ссылается на стандартные `minecraft:block/cauldron_top`, `cauldron_side`, `cauldron_bottom`, `cauldron_inner`. Ванильные PNG не изменялись и не заменялись. Их встроенные копии в проектах Blockbench нужны для автономного просмотра. Текстуры/геометрия исходного котла принадлежат Mojang/Microsoft и взяты из Minecraft 1.21.1.

Для прозрачного atlas деталей котла объявлен `render_type: minecraft:cutout`, который поддерживает NeoForge. Это только параметр визуальной модели. В проекте котла Blockbench параметр сохранён в `unhandled_root_fields` для последующего экспорта.

## Проверено

- Размер всех 22 PNG: 16×16. Основные поверхности полностью непрозрачны; анимации отсутствуют.
- JSON разбираются; родители моделей и ссылки на все текстуры разрешаются по созданным файлам или стандартным ресурсам Minecraft 1.21.1.
- Координаты cuboid-элементов находятся в допустимых пределах; UV в диапазоне 0–16; поддерживаемые углы вращения.
- 324 сравнения стыков: 18 для верха, 288 между всеми боковыми текстурами и 18 для низа. Все пройдены.
- 13 cuboid-элементов железного котла по JSON-значениям совпадают с оригинальными.
- Все шесть проектов открыты в Blockbench 4.12.6, встроенные текстуры загрузились. Сняты одиночный блок, два соседних, площадка 3×3, объём 3×3×2, три вида котла и сравнение с ванильным.
- Проверка в Minecraft не проводилась: новые блоки не регистрировались. Gradle/Java в этой графической задаче не требуются.

Готовы PNG, JSON и проекты для последующей интеграции. Позже отдельно понадобятся регистрация/привязка блоков, blockstates и выбор вариантов. Механики котла, взаимодействия, CTM, генерация мира и Java-код здесь не создавались. Существующие ресурсы других блоков не изменялись. Git commit/push не выполнялись.

Полный перечень файлов — `CREATED_FILES.txt`. Машиночитаемые проверки — `verification.json` и `blockbench-validation.json`.

## Уточнение визуала: органы, кишки, кости и связные потёки

Обновлены шесть верхних/боковых текстур блока: появились округлые лопасти тканей с вырезами, извилистые петли кишок и редкие маленькие фрагменты костей. Палитра приглушённая, края вариантов согласованы между собой. Края всех семейств текстур сохранены.

Основная поверхность мяса в котле rotting_meat_cauldron_surface.png сохранена побайтово. Чтобы новые детали блока не изменяли мясо внутри котла, прежние боковые материалы сохранены отдельными rotting_meat_cauldron_side.png и rotting_meat_cauldron_side_variant_2.png; модель котла использует их. Их пиксели полностью совпадают с прежними боковыми материалами до этой правки. Первые 24 элемента исходного котла (железо и основное мясное наполнение) также сохранены.

Добавлены два небольших выступающих фрагмента. Вместо отдельных несвязанных пятен сделаны четыре пары потёков: две на передней и две на правой стенке. В каждой паре пятно проходит от содержимого через верх бортика и продолжается на стенке. Верхняя и вертикальная плоскости сходятся на одной кромке; UV развёрнуты с учётом стороны, а ряд цвета и прозрачности на стыке совпадает.

JSON/UV, размеры PNG, все 324 стыка вариантов и сохранность материалов котла проверены повторно. Шесть проектов открыты в Blockbench 4.12.6, все текстуры загрузились, превью обновлены. Java-код и игровые механики не менялись.

## Шесть самостоятельных граней и больше кишечных складок

Во всех трёх моделях теперь заданы разные текстуры up/down/north/east/south/west: 18 различных композиций. Увеличено количество кишечных петель, изменены положение органов, гнилостных участков и редких костяных фрагментов. Использованы осмысленные связные формы; случайного пиксельного шума нет. Композиции заранее подготовлены в PNG, при открытии модели они остаются фиксированными.

Названия top и side сохранены для совместимости: side — северная грань, остальные боковые рисунки имеют суффиксы side_east, side_south, side_west. У вариантов B/C каждый из шести файлов дополнен _variant_2/_variant_3. Низ также имеет три собственных рисунка.

Модульность: все двенадцать боковых рисунков имеют общие края; верхние три согласованы между собой, нижние три — между собой. Проверены все 324 сочетания граничных рядов/столбцов. Уникальность проверена и для внутренних областей всех 18 текстур. Для совместимых стыков сохраняйте ориентацию UV. Автоматический случайный выбор моделей между игровыми блоками не добавлялся — это будущая привязка ресурсов при интеграции.

Все PNG и JSON-модель котла в этой правке сохранены побайтово. Текстуры его содержимого, потёки и геометрия не менялись. Java-код не затрагивался.

`previews/face-layouts.png` показывает все шесть граней каждого варианта.

## Распределение по краям, углам и всей поверхности

Убрано ограничение, удерживавшее крупные формы внутри центральной области. Петли кишок и органы теперь размещаются в разных квадрантах, у углов и непосредственно на границах; часть форм обрезана краем и имеет фрагменты на противоположной стороне рисунка. Между скоплениями остаются спокойные участки ткани. Для каждой из 18 граней отдельно выбираются позиции, позы, зеркальные отражения и оттенки связных анатомических мотивов с фиксированным seed. Это случайная расстановка осмысленных элементов, зафиксированная в PNG.

Модульность поддерживает один общий пиксель края и несколько коротких стыковочных рукавов складок. Проверены 324 сравнения границ после перераспределения. Уникальность всех 18 внутренних композиций сохранена. Используйте комплект текстур целиком: он согласован между своими вариантами, прежние версии отдельных граней могут иметь другой рисунок кромки.

Котёл и его материалы сохранены побайтово. Код игрового выбора вариантов не добавлялся.

## Уменьшена плотность кишечных петель

Второстепенные петли укорочены примерно вдвое по числу узлов рисунка. Основные складки, положение органов, кости, расстановка по краям/углам и совместимые кромки сохранены. Стало больше открытой мясной ткани между петлями. Все 18 граней остаются разными. Модель и материалы котла не менялись.

## Кишечные складки без коричневой обводки и немного больше костей

Тёмная нарисованная обводка кишечных петель убрана, в том числе на стыковочных продолжениях. Объём передан близкими приглушёнными розовато-серыми оттенками ткани. Толщина и сокращённые траектории петель сохранены. Очертания органов, естественные тёмные полости фоновой массы и случайная расстановка элементов не менялись.

Маленькие костяные фрагменты добавлены ещё на три грани: теперь они заложены в восемь из 18 рисунков вместо пяти. Размер отдельных фрагментов сохранён. Модель и все материалы котла остаются прежними.

## Светлая обводка, меньше петель и маленькие черепа

Обводка кишечных складок возвращена в более светлом, холодном серо-красном цвете RGB 105/78/76 вместо прежнего тёмно-коричневого. Штрих виден как теневая грань ткани; светлая внутренняя линия сохраняет объём. Такой же материал использован на стыковочных продолжениях.

Половина второстепенных петель убрана: всего 27 кишечных мотивов вместо 36 на 18 рисунках. Основные позиции и случайная раскладка остальных элементов сохранены. Добавлены три небольших пиксельных черепа 5×6: восток варианта A, юг варианта B и верх варианта C. Цвет приглушённый костяной, два глазных углубления и небольшая челюсть. Это вкрапления в текстуре, геометрия полного куба не менялась.

Все 324 стыка проверены. Модель и материалы котла сохранены без изменений.
