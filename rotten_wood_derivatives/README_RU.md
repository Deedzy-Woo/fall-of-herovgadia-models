# Гнилые деревянные блоки — визуальные модели для Blockbench

48 самостоятельных редактируемых `.bbmodel`: 8 пород × 6 типов.

Это визуальные исходники для оценки. Java-кода, регистрации, рецептов и интеграции в мод здесь нет.

## Как открыть

1. Распакуйте ZIP.
2. В Blockbench выберите **Файл → Открыть модель**.
3. Откройте `blockbench/<порода>/rotten_<порода>_<тип>.bbmodel`.

Все PNG уже встроены внутрь каждого проекта. Подключать текстуры вручную не требуется.
Отдельные PNG дополнительно лежат в `textures/`; размер каждой — 16×16.

## Состав

Породы: oak, spruce, birch, jungle, acacia, dark_oak, mangrove, cherry.
Типы: stairs, slab, fence, fence_gate, door, trapdoor.

Ступенька показана прямой нижней, плита — нижней, калитка — закрытой,
люк — закрытым нижним. Забор показан в ванильной форме для инвентаря с
двумя стойками и перекладинами. Дверь — целиком, два редактируемых элемента
`door_bottom` и `door_top`, размер 1×2 блока, толщина 3/16 блока.
Геометрия и UV перенесены из соответствующих шаблонов Minecraft Java 1.21.1.
Формат исходника — `java_block` (Blockbench).

## Текстуры

Обычные `rotten_<порода>_planks.png` взяты из приложенного архива без изменения байтов.
Потрескавшиеся доски и брёвна не используются.

Для дверей каждой породы сделаны отдельные верхняя и нижняя PNG.
Для люков — отдельная PNG каждой породы. В основе именно соответствующие
ванильные текстуры, с палитрой исходных гнилых досок, потускневшей фурнитурой
и сдержанными пятнами старения, немного сильнее внизу дверей.
Оригинальные прозрачные проёмы сохранены попиксельно.

| Порода | Сохранённые особенности двери и люка |
|---|---|
| Oak | Четыре окна, диагональные перемычки нижних панелей; четыре отверстия люка. |
| Spruce | Вертикальные доски, металлические скобы и ручка; скобы на люке. |
| Birch | Светлые утопленные прямоугольные панели; цельный рамочный люк. |
| Jungle | Ступенчатый оконный вырез и филёнки; характерные вырезы люка. |
| Acacia | Высокие вертикальные прорези, узкая рама и петли. |
| Dark Oak | Парные филёнки, тёмная рама и приглушённая латунная ручка; четыре глухие панели люка. |
| Mangrove | Красноватая декоративная филёнка; центральное отверстие люка. |
| Cherry | Резные проёмы верхней половины, розоватые панели; решётка люка. |

## Проверка

Все 48 проектов загружены в настоящую веб-версию Blockbench,
проверены встроенные текстуры, грани, число редактируемых элементов
и сохранение через project codec. Снимки `previews/all_48_models.png`
и `previews/doors_blockbench.png` получены из окна 3D-просмотра Blockbench.
`previews/doors_and_trapdoors.png` — плоское превью PNG с nearest-neighbor.
Подробности — `blockbench-validation.json` и `manifest.json`.

Это проверка визуальных моделей в Blockbench; Minecraft и Gradle не запускались,
поскольку по уточнению задачи нужна только библиотека моделей с текстурами.
